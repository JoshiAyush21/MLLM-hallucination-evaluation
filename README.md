# MLLM-hallucination-evaluation
This project aims to evaluate Multimodal-Large Language Models (MLLMs) like InstructBLIP and Open-Flamingo and identifies hallucination scenarios based on various augmentatios applied to input image-prompt pairs.
Analyzing and Mitigating situations where the model produces outputs that are not anchored in the input data or real-world facts. Such outputs might involve the generation of fictitious information, scenarios, or details that either do not exist in the training data or are not relevant to the context.
